# Movie Library

A console-based movie library manager written in Java. Add movies to a personal
collection, rate them, mark them as watched, and search or filter your list.

## Features

- Add movies with title, director, year, genre, and rating
- Remove movies from the library
- List all movies
- Mark movies as watched (with rating)
- Search by director or genre
- Filter by minimum rating or year range
- View watched and unwatched movies

## How to Run

1. Clone the repository
2. Open the project in IntelliJ (or compile with `javac`)
3. Run `Main.java`

## What I Learned

I made this project to practice object-oriented programming in Java and get

things along the way, like enhanced for loops.
